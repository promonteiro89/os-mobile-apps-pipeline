# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in this project's issues, pull requests and discussions is expected to follow it.

## Reporting

Report unacceptable behaviour privately to the repository owner through GitHub (for example with the repository's **Security** tab → **Report a vulnerability**, which only the maintainers can see, or by contacting the owner from their GitHub profile). Don't report it in a public issue.

Reports are reviewed by the maintainers, who will respect the privacy of the reporter. Enforcement follows the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
